# Branding

Generated branding assets for HACS, Home Assistant and GitHub previews.

- `../../icon.png`: square repository icon for HACS
- `../../logo.png`: landscape repository logo for HACS
- `../../banner.png`: wide banner for README usage
- `../../repository-open-graph.png`: social preview image for GitHub
- `../../custom_components/room_climate/icon.png`: integration-local icon
- `../../custom_components/room_climate/icon@2x.png`: integration-local hDPI icon
- `../../custom_components/room_climate/logo.png`: integration-local landscape logo
- `../../custom_components/room_climate/logo@2x.png`: integration-local hDPI logo

Regenerate with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\generate-branding.ps1
```
